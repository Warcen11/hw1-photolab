## 2. Три вопроса

**2.1. Какое цветовое пространство выбрано для хромакея и почему? Что было бы в RGB?**

Для хромакея использовано HSV. В нём оттенок H отделён от насыщенности S и яркости V, поэтому диапазон цвета проще задавать независимо от изменений освещения и теней. В RGB изменение яркости одновременно меняет R, G и B, поэтому один диапазон по каналам хуже описывает один и тот же цвет при разном освещении. На моём изображении итоговая HSV-маска заняла 6.46 % кадра, а на тестовом `ball-lamp.jpg` дала recall 91.4 % и precision 100.0 %.

**2.2. Что происходит с гистограммой при γ < 1 и при γ > 1? Куда деваются обрезанные пиксели?**

При γ < 1 тёмные значения растягиваются в сторону больших яркостей, поэтому изображение светлеет: на моём фото средняя яркость выросла с 12.5 до 53.8. При γ > 1 значения сжимаются к нулю, поэтому изображение темнеет: при γ = 2 средняя яркость стала 0.9, а 77.98 % пикселей после преобразования и округления стали равны нулю. Перед переводом обратно в `uint8` значения дополнительно ограничиваются диапазоном [0, 255], чтобы исключить переполнение.

**2.3. Почему CLAHE лучше `equalizeHist` на вашем фото — по числам из 1.3? Если не лучше — что измерили и почему?**

На моём фото CLAHE дал более умеренное усиление локального контраста. В тенях σ выросла с 0.8 до 1.5, а средняя яркость светлых областей — с 22.0 до 41.2. `equalizeHist` увеличил σ в тенях до 18.0, но одновременно поднял среднюю яркость светов до 228.3, из-за чего изображение стало слишком жёстким и визуально пересвеченным. Поэтому CLAHE дал более естественный результат.

## 3. Где сломалось

Первое проблемное место — CLAHE на `data/dark.jpg`. Исходный кадр оказался слишком тёмным: средняя яркость теней была 4.7, после CLAHE стала только 8.9, а σ в тенях выросла с 0.8 до 1.5. То есть локальный контраст увеличился, но визуально изображение всё равно осталось очень тёмным. `equalizeHist` дал намного более сильный эффект, но перегнул в другую сторону: средняя яркость светов выросла до 228.3, поэтому картинка стала слишком жёсткой и пересвеченной. Помог бы менее экстремально недоэкспонированный исходный кадр либо дополнительный подбор `clipLimit`, потому что на текущем фото большая часть теневых значений находится слишком близко к нулю.

Второе проблемное место — хромакей для `data/object.jpg`. У объекта есть тонкие лапки, тени и участки с разной яркостью, а часть фона имеет близкие жёлто-коричневые оттенки. Слишком узкий HSV-диапазон терял лапки и теневые участки, а слишком широкий начинал захватывать фон. После настройки диапазона до `lo=[15,60,10]`, `hi=[29,200,255]` и морфологии `open=2`, `close=9` число компонент уменьшилось с 1479 до 328, но в итоговой маске осталось 17 дыр. На тестовом `ball-lamp.jpg` маска дала precision 100.0 % и recall 91.4 %: лишний фон почти не захватывается, но часть объекта теряется. Помог бы более однородный по цвету объект либо фон, сильнее отличающийся от него по hue/saturation; тогда диапазон можно было бы расширить для теневых участков и лапок, не захватывая фон.

## 4. Команды

Все финальные файлы в `out/` получены следующими командами:

```bash
python photolab.py gamma data/dark.jpg --gamma 0.5 -o out/dark_g05.jpg --hist out/dark_g05_hist.png
python photolab.py gamma data/dark.jpg --gamma 2 -o out/dark_g2.jpg --hist out/dark_g2_hist.png

python photolab.py wb data/bright.jpg --method grey-world -o out/bright_gw.jpg --hist out/bright_gw_hist.png
python photolab.py wb data/bright.jpg --method white-patch -o out/bright_wp.jpg --hist out/bright_wp_hist.png

python photolab.py clahe data/dark.jpg --clip 2 --tiles 8 -o out/dark_clahe.jpg --compare out/dark_cmp.jpg --hist out/dark_clahe_hist.png

python photolab.py chromakey data/object.jpg --bg data/bg.jpg --lo 15,60,10 --hi 29,200,255 --open 2 --close 9 --feather 1.0 -o out/object_on_bg.jpg --mask out/object_mask.png

python photolab.py rotate data/poster.jpg --deg 30 -o out/poster_rot30.jpg

python photolab.py resize data/text.jpg --scale 0.25 --method area --report -o out/text_area.jpg
python photolab.py resize data/text.jpg --scale 0.25 --method blur -o out/text_blur.jpg
python photolab.py resize data/text.jpg --scale 0.25 --method naive -o out/text_naive.jpg

python photolab.py rectify data/poster.jpg --corners 412.5,302.5,1150.0,297.5,1452.5,1065.0,100.0,1057.5 --aspect 0.707 -o out/poster_rect.jpg

python photolab.py sheet out/dark_g05.jpg out/dark_g2.jpg out/bright_gw.jpg out/bright_wp.jpg out/dark_clahe.jpg out/object_on_bg.jpg out/poster_rot30.jpg out/text_area.jpg out/poster_rect.jpg --cols 3 -o out/sheet.jpg
```
